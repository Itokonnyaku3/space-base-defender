# Wave 5 ボス：巨大戦列艦 設計書（spec）

- **作成日**: 2026-06-14
- **対象**: Wave 5 のボス戦（現状の簡易「巨大母船」を置き換える）
- **関連**: [GAME_DESIGN_IDEAS.md](../../GAME_DESIGN_IDEAS.md)（3-E コア露出ボスの発展）、[ARCHITECTURE_REVIEW.md](../../ARCHITECTURE_REVIEW.md)
- **状態**: ユーザー合意済み（味方機の指示機能は Wave 4 へ分離）

---

## 1. 面白さの核（design intent）

> **「遅い攻城戦のタイマン」**。巨大戦艦が基地へ迫る重圧の中で、
> **機関を潰して時計を止め → 露出した波動砲を長距離弾で撃ち抜く**という一本道の勝ち筋を、
> 慣性操縦での位置取りと、5秒チャージの長距離弾の運用で達成する。

プレイヤーが迫られる判断・技術:
- **位置取り**: 横長の船体を慣性で回り込み、機関（後方）・発射台（側面）へアクセスする
- **優先順位**: 発射台（増援源）を潰すか無視するか、即死ビームをどう避けるか
- **タイミング**: 波動砲チャージ 30秒の窓で、5秒CTの長距離弾を4発確実に当てる

---

## 2. ゲームフロー（2フェーズ）

### フェーズ1：進軍を止める
- 戦艦は基地へ向かって**ゆっくり直進**（前方＝基地方向の固定向き）。
- **推進機関 ×4**: 破壊するごとに減速。速度 = `基本速度 × (生存機関数 / 4)`。**4基すべて破壊で実質停止 → フェーズ2へ移行**。
- **発射台（左右に1基ずつ）**: 一定間隔で敵を射出。
  - 射出される敵は2種を交互: **迎撃機**（自機を追尾）/ **爆撃機**（基地へ突撃）。既存の敵AIを流用。
  - 各発射台は**左右の防壁2枚**でガード。**防壁を両方壊す → 発射台が破壊可能に → 破壊するとその発射台からの射出が停止**。
- このフェーズ中は**戦艦を撃破できない**（波動砲は未露出）。唯一できるのは機関破壊（進軍停止）と発射台破壊（増援停止）。
- 放置すると戦艦が基地に到達し、基地に大ダメージ（＝実質敗北）。**だから機関破壊が最初の目的**になる。

### フェーズ2：波動砲（全機関破壊後）
- 戦艦は停止。攻撃を**波動砲**に切替、**前方の砲台が露出**。
- **30秒チャージ**（視覚的に分かるゲージ＋発光演出）。
- チャージ完了 → 基地へ**40ダメージ**の砲撃 → **再チャージ（ループ）**。
- **即死ビーム**: チャージ完了の**砲撃の瞬間**、基地へ直進するビーム経路（＝予告線上）に自機がいると**一撃で撃破**。チャージ中ずっと**ビーム予告線**を表示し、砲撃の瞬間までに線上から退避させる（チャージ中の予告線自体は無害、危険なのは発射の瞬間）。
- **勝ち筋**: 露出した波動砲に**長距離弾を計4発命中** → 波動砲破壊 → チャージ中のエネルギーで**戦艦が爆発＝ボス撃破（Wave 5 クリア）**。
  - 波動砲にダメージを与えられるのは**自機の長距離弾のみ**（マシンガン・タレット弾・味方弾は無効）。
  - **命中数は露出中のみ蓄積し、チャージ完了（砲撃）に至ってもリセットしない**（波動砲の耐久＝長距離弾4発。露出していない時は無敵）。
  - 4発当てる前に砲撃されると基地に40ダメージ→再チャージで再挑戦。基地HPが尽きる前に決める緊張。

## 3. パーツ構成と空間レイアウト

戦艦は**複合ボス**（親船体＋子パーツ群）。各パーツは独立HP・独立当たり判定を持ち、船体の変形に追従して毎フレーム位置更新する。

| パーツ | 数 | 位置 | 役割 | 破壊できる武器 |
|---|---|---|---|---|
| 船体（hull） | 1 | 横長中央 | 移動本体・パーツの基準 | （直接撃破不可） |
| 推進機関（engine） | 4 | 後方 | 進軍の推力。破壊で減速→停止 | 全武器 |
| 発射台（launch bay） | 2 | 左右側面 | 敵の射出元 | 防壁破壊後に全武器 |
| 防壁（guard wall） | 4（各発射台に2） | 発射台の左右 | 発射台のガード | 全武器 |
| 波動砲（wave cannon） | 1 | 前方 | フェーズ2で露出。勝利の鍵 | **長距離弾のみ（4発）** |

向きは**スポーン時に基地方向へ固定**（前方＝基地、後方＝機関、ビームは前方＝基地へ直進）。これにより部位配置・ビーム方向の計算を単純化する。

## 4. 調整可能パラメータ（`configs/BossConfig.ts` に外出し）

すべて単一情報源として config に置く（ハードコード禁止の方針に従う）。初期値は提案。実プレイで調整する。

```
battleship:
  baseAdvanceSpeed: 6          # 全機関生存時の進軍速度（px/秒・フレーム非依存。実プレイ調整値）
  engineCount: 4
  engineHp: 50                 # 1基あたり
  launchBayHp: 60
  guardWallHp: 40              # 1枚あたり
  launchIntervalMs: 13000      # 各発射台の射出間隔
  waveCannon:
    chargeMs: 30000            # チャージ時間
    baseDamage: 40             # 砲撃が基地に与えるダメージ
    longRangeHitsToDestroy: 4  # 破壊に必要な長距離弾命中数
    beamInstantKill: true      # 自機がビーム経路にいると即死
launchedEnemies:
  interceptorId: 'single_circle'  # 自機追尾（既存）
  bomberId: 'suicide_bomber'      # 基地突撃（既存）
```

## 5. 勝敗条件

- **勝利（Wave 5 クリア）**: 波動砲を破壊（チャージ中に長距離弾4発）→ 戦艦爆発。既存の `clearConditions.destroyCarrierMothership` を流用（戦艦＝母艦の詳細版）。
- **敗北**: 既存どおり基地HP 0 または自機HP 0。基地HPは フェーズ1の爆撃機 ＋ フェーズ2の波動砲砲撃（40/回）＋ 戦艦が基地到達した場合の大ダメージ、で削られる。

---

## 6. アーキテクチャ / 実装方針

- **新規モジュール** `src/game/bosses/Battleship.ts`（仮）にボスを集約。MainScene からは「Wave 5 開始時に生成」「毎フレーム update を回す」「撃破/基地被弾を通知」のみ。既存戦闘には極力触れない**追加実装**（デグレ低リスク）。
- **パーツ**: Phaser スプライト＋ `setData('hp')` 等（既存の EntityData 方式）。当たり判定は既存の弾グループ × ボスパーツのコライダーを追加（`hitOutpost` 同様のダメージ処理を流用）。
- **波動砲の特殊判定**: 「長距離弾のみ・チャージ中のみ・4発」をボス側で判定（弾の `weaponType === 'long_range'` を見る）。
- **純粋ロジックの分離（テスト容易性）**: 状態遷移（機関数→速度、フェーズ移行、チャージ・タイマー、勝利判定）を Phaser 非依存の純関数/小クラス `BattleshipState` に切り出し、**vitest で単体テスト**する。描画・物理は MainScene 側。
- **config**: `configs/BossConfig.ts` を新設（§4）。
- **演出**: チャージゲージ・ビーム予告線・露出砲台の発光・爆発は Phaser Graphics / 既存 `triggerExplosion` を流用。
- **通信での誘導（データ駆動）**: シナリオJSONの Wave5 イベント/動的イベントで「機関を潰せ」「波動砲チャージ中、長距離弾を当てろ！」等を表示（既存の通信UI・ScenarioManager を流用）。

### Wave 5 統合
- 現状の `spawn_mothership` / `handleWaveTransition('wave5')` のセットアップを**戦艦生成に置換**。
- 既存の簡易 `mothership`（ENEMY_CONFIGS.mothership・updateMotherships・hitMothership）は Wave 5 では使わない（他で未使用なら段階的に整理。当面は温存可）。

## 7. スコープ外（このspecに含めない）

- **味方機への指示機能**（敵/構造物破壊・タレット設置）→ 味方機が初登場する **Wave 4 の設計**でまとめて扱う。Wave 5 のボスは味方機がいてもいなくても成立する設計とする。
- 母船関連の旧コード（updateMotherships/hitMothership/ENEMY_CONFIGS.mothership）の削除は本specの必須事項ではない（リスク回避のため別途）。

## 8. テスト

- **vitest（自動）**: `BattleshipState` の純ロジック
  - 機関破壊数 → 速度スケーリング（4→0で停止）
  - 全機関破壊でフェーズ2へ移行
  - チャージタイマー（30秒到達で砲撃イベント、ループ）
  - 波動砲：チャージ中に長距離弾4発で撃破フラグ、チャージ外の命中は無効
  - 発射台：防壁全破壊前は発射台破壊不可、破壊後は射出停止
- **実機プレイ確認（必須）**: 当たり判定・即死ビーム回避の手触り・各HPと時間のバランス・演出。新規システムのため自動検証できない部分はユーザーがプレイで確認。
